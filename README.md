Скрипт создан для друзей Телеграм канала [Клуб «На связи»](https://t.me/na_sviazi66)

Что это?
Этот скрипт позволяет развернуть полную инфраструктуру MTProxy-сервера для Telegram с защитой от блокировок и удобной веб-панелью управления. Всё что нужно — запустить одну команду, и через несколько минут у вас будет готовый прокси с возможностью управления через веб-интерфейс и Telegram бота.

Зачем это нужно?
Telegram часто блокируют на уровне провайдеров. MTProxy с маскировкой под обычный HTTPS-трафик (TLS-fronting) помогает обойти эти ограничения. Скрипт автоматически настраивает:

Основной прокси-сервер telemt

Web панель для удобного управления

Telegram бота для удалённого администрирования

HTTPS с самоподписным сертификатом (WebSocket работает корректно)

Возможности
🔧 Основной прокси (telemt)
🚀 Автоматическая установка — компилирует telemt из исходников, настраивает systemd, создаёт системного пользователя

👥 Управление пользователями — добавляйте, удаляйте, просматривайте список (каждый получает свою ссылку)

🔒 Ограничение по IP — можно настроить, чтобы ссылкой мог пользоваться только один человек одновременно

🔌 Смена порта — по умолчанию 7443, можно изменить на любой

🎭 Смена SNI — маскируйте трафик под легитимные сайты (google.com, cloudflare.com и другие)

🌐 Web панель
📊 Dashboard — статистика подключений, активные IP, трафик в реальном времени

👥 Управление пользователями — просмотр, добавление, удаление через веб-интерфейс

🔧 Настройка прокси — смена порта, SNI, лимитов

🔒 HTTPS поддержка — работает через Nginx с самоподписным сертификатом

🔌 WebSocket — корректно настроен, данные обновляются в реальном времени

🤖 Telegram бот

👥 Управление пользователями — создание, удаление, просмотр списка

🔧 Смена настроек — порт, SNI, лимиты IP

🔄 Перезапуск telemt — прямо из Telegram

🔄 Общие функции
📋 Статус и информация — полная диагностика системы
